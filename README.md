# LarpFetch
LarpFetch is simple NeoFetch like tool witten in Rust.
## NOTES
 - LarpFetch is Beta and it may contains bug. And some parts are unfinished

 - Logos / Icons are from FastFetch and they are not licensed under MIT!
## Install
# Download file
Download latest archive for you system [here]() and extract it where you wanna have LarpFetch installed and run it 
# Build from source
Clone github repo:
´git clone https://github.com/LordJiriX/LarpFetch.git & cd LarpFetch´
then:
´cargo build´
